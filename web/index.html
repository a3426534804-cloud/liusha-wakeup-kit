如何读懂“命中”和费用？

读取比例 = 缓存读取 ÷（缓存读取 + 缓存创建 + 非缓存输入）。有读取，也可能同时产生新写入。大量创建不一定意味着整段上下文冷重建。

“≥”表示仅拿到部分 usage，费用是已知输入的下限；未知费用显示“未回报”，不会当成零费用。

演示使用合成数据与示意价格，没有接入真实会话。生产版本应以逐条 usage 和账单核对。
